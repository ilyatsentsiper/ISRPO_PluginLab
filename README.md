# Лабораторная работа: Плагин автогенерации ML-кода для VS Code

Реализация нативного расширения для автоматизации написания шаблонного кода машинного обучения и анализа данных.

## Основной функционал
* **Интеграция в палитру команд:** Добавление команды `Generate ML Pipeline` в глобальное меню IDE (`F1` / `Ctrl+Shift+P`).
* **Поддержка горячих клавиш:** Мгновенный вызов генерации по сочетанию клавиш `Ctrl + Alt + P`.
* **Автоматическая инъекция пайплайна:** Динамическое определение позиции курсора в активном текстовом редакторе и вставка синтаксически корректного шаблона классического машинного обучения на Python (`scikit-learn`, `pandas`).

## Генерируемый ML-пайплайн включает:
1. Импорт базовых библиотек для анализа данных и машинного обучения.
2. Чтение датасета из CSV-файла с помощью `pandas`.
3. Разделение признаков и целевой переменной (`X`, `y`).
4. Разбиение выборки на обучающую и тестовую (`train_test_split`).
5. Инициализацию и обучение классической модели ансамблей (`RandomForestClassifier`).
6. Расчет и вывод метрик качества классификации (`classification_report`).

## Архитектура
1. **Активация (`ActivationEvents`):** Используется ленивая загрузка с триггером `onStartupFinished`. Плагин активируется в фоновом процессе (Extension Host) сразу после полной загрузки графического интерфейса IDE.
2. **Модификация текста (`TextEditor API`):** При вызове команды плагин запрашивает контекст активного окна (`vscode.window.activeTextEditor`), считывает координаты курсора (`selection.active`) и выполняет атомарную асинхронную вставку текстового блока (`editBuilder.insert`).

## Сборка и установка
Проект упакован в готовый дистрибутив расширения с расширением `.vsix` с помощью утилиты `vsce`.

### Ручная установка из файла:
1. Откройте VS Code.
2. Перейдите во вкладку **Extensions** (`Ctrl + Shift + X`).
3. Кликните на меню с тремя точками `...` в верхнем углу панели расширений.
4. Выберите **Install from VSIX...** и укажите путь к сгенерированному файлу `ml-generator-0.0.1.vsix`.
